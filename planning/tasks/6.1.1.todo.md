## Notes
- Analysis: `R0Val` (src/value.rs) has variants Dbl, Int, Lgl(u8: 0/1/2), Chr(Option<String>), Range{start,end,step}, Df{names,cols}, List{names,cols}, Null. `is_na_real` distinguishes NA from NaN by payload; `NA_INT = i32::MIN`. `R0Vm::eval_script` is in src/vm.rs (not needed by 6.1.1 itself).
- Rscript 4.6.2 at /usr/bin/Rscript. Invoked only with a file argument; no `-e`.
- Format decided (no spec text for indentation, so picked this): `<typeof>[<len>]:` followed by ` <elem>` per element (no trailing space on empty). Lists: `list[<n>]` then per element a line `  "<escaped name>"` (`""` when unnamed) followed by the child's lines indented by 4 spaces. Data frames use `data.frame[<ncols>]` with the same element layout. Typeof names: `double`, `integer`, `logical`, `character`, `NULL`, `list`.
- `%.15g`: Rust `format!("{:.14e}")` rounds correctly to 15 significant digits; exponent X decides fixed (-4 <= X < 15) vs exponential. R uses C sprintf, so the outputs agree.
- Constraints: no changes to src/**, conformance.rs, Makefile, docs/**, tests/r0/**; no Cargo.toml changes; no `cargo fmt`; planning file stays uncommitted.
- Risks: Df `len` in R0Val uses first column length; R side uses `length(x[[1]])`. Empty Df with zero columns: both emit `data.frame[0]:` header only.
