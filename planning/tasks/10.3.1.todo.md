## Notes
- Rscript 4.6.2 (`$HOME/scratch_r10/g21.R`, `g21b.R`):
  - `typeof(diff(1:5, lag = 2))` = integer; `diff(c(1L,4L,9L))` integer; `diff(c(1,4,9))` double; `diff(1L)` integer(0).
  - `diff(c(NA_integer_,1L,4L))` = NA, 3 (integer).
  - `diff(c(-2147483647L, 2L))` = NA (integer) with a warning. R0 has no warning channel; the value matches, the warning is not modelled.
  - Data frame single-index assignment REPLACES the column with the RHS type: double col + `d[1] <- 2L` gives integer; int col + `d[1] <- 2.5` gives double; int col + `d[c(1,2)] <- 7L` gives integer.
- Current R0 (probe): `d[1] <- 2L` on a double column gives Dbl (coerced to the column type), so it diverges. Int col and dbl RHS already match.
- `d[2] <- NA` on a one-column df errors `ErrBoundsTrap` in R0. GNU R extends. That is a separate existing gap (not G21). Not in scope; record it.
- The `subset_assign` D3 rule (keep target type) is still used by 2-index assignment (`d[i, j] <- v`) and is not changed.
