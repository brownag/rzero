# 12.1.2 -- Lexer `\` introducer and transpiler test (G25, G30)

## Goal
Make `\(` lex as `Tok::Fn` so `\(x) x + 1` behaves exactly like `fn(x) x + 1`, with a transpiler test proving it emits `function(x)`.

## TODO items
- [ ] In `src/lexer.rs` `tokenize`, add a branch (before the final `match c` fallthrough, next to the identifier/keyword handling) for `c == '\\'`: scan `j` past spaces/tabs after `i+1`; if `bytes[j] == b'('`, push `Tok::Fn`, set `i += 1` (the `(` is then lexed normally), `continue`.
- [ ] If `\` is not followed by `(`, fall through unchanged so `Unexpected character: '\'` is still produced.
- [ ] Lexer test: `toks("\\(x) x + 1") == toks("fn(x) x + 1")`.
- [ ] Lexer test: `\ (x) x` (whitespace before `(`) also equals `fn (x) x`.
- [ ] Lexer test: `tokenize("\\")`, `tokenize("\\x")`, `tokenize("\\\n(x)")` each return `Err("Unexpected character: '\\'")` (newline is not skippable whitespace).
- [ ] Transpiler test (test module only) in `src/transpile.rs`: `t("f <- \\(x: dbl) -> dbl x + 1") == "f <- function(x) x + 1"`.
- [ ] Run `cargo test --lib lexer` and `cargo test --lib transpile` (exit 0).
- [ ] Run `cargo clippy` and `cargo fmt --check` clean; `cargo build --target wasm32-unknown-unknown --release` OK.
- [ ] Confirm `git diff --stat` lists only `src/lexer.rs` and `src/transpile.rs`. Do not commit until told.

## Notes
- Lexer is a byte loop `tokenize` (`src/lexer.rs:112`); `Tok::Fn` comes from the ident branch at :239. The `\` error is the `_ =>` arm at :355 in the single-char `match c`; `ch` there is the first char of `rem`.
- Header detection (`Open::Header`, :332) keys off the previous token being `Tok::Fn` (to confirm at :325-332), so emitting `Tok::Fn` makes the `(` a header with no other change; the transpiler (`Tok::Fn => pending_fn`, :109) then needs no source edit and strips types as for `fn`.
- Transpiler prints `Tok::Fn` as `function`, so `\` normalizes to `function`.
- Existing lexer tests use `toks(src)` helper and `assert_eq!` on `Vec<Tok>`; the error test uses `tokenize(..).unwrap_err()` with exact message (:446). Transpiler tests use helper `t`.
- Constraints: no edits to vm.rs, value.rs, parser.rs, tests/; transpile.rs edits confined to `mod tests`.
- Risk: `\` inside string literals/comments is handled earlier by those branches, so unaffected.
