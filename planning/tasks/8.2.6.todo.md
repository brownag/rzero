## Notes
- Value asserts migrated: 37 expressions (of 39 value asserts in the Rust function).
  - `prod`: 10 (`prod_*`). Includes `prod(c())` (bare Null argument, see Questions 1), `prod(c(2, NA_real_, 4))` (NA), `prod(c(2, NaN, 4))` (NaN).
  - `var`: 8 (`var_*`). Excludes `var(c(1, NaN, 3))` (D-8.4).
  - `sd`: 7 (`sd_*`). Excludes `sd(c(1, NaN, 3))` (D-8.4). `sd(c(1, 3))` and the `na.rm` case are the sqrt(2) checks, carried as full values (see Questions 2).
  - `median`: 12 (`median_*`). All kept, including the 3 NA asserts (`numeric(0)`, `c(1, NA_real_, 3)`, `c(1, NaN, 3)`) and the all-NA `na.rm` case.
- Error asserts kept in Rust: 8 (eval_err `starts_with`/`contains`).
  - `TypeError`: 2 (`prod(1, na.rm = "foo")`, `sd(1, na.rm = 1)`).
  - `ErrInvalidCondition`: 1 (`var(1, na.rm = NA)`).
  - `UnknownArgument`: 1 (`median(1, unknown = 1)`).
  - Missing argument: 4 (`prod()`, `var()`, `sd()`, `median()`).
- Exclusions applied: 2 (D-8.4, `var(c(1, NaN, 3))` and `sd(c(1, NaN, 3))`). No H4 exclusion expected here: `prod(NULL)` returns 1 in GNU R, so `prod(c())` is not an H4 error case (not verified by Rscript in this planning step; the harness run is the check).
- Risks:
  - Float values: `sd(c(1, 3))` and `sd(c(1, NA_real_), ...)` produce sqrt(2) = 1.4142135623730951. The Rust test uses a 1e-12 tolerance; the corpus relies on the canonical text match. If the canonical form differs in the last digit, the harness fails. Report, do not round.
  - `NA` vs `NaN`: `prod(c(2, NaN, 4))` must be NaN, `median(c(1, NaN, 3))` must be NA (`is.na(NaN)` is TRUE in GNU R's median). The canonical form must separate them, as in 8.2.5.
  - Single-observation `var`/`sd` return NA in both. `median` of all-NA with `na.rm = TRUE` returns NA in both.
