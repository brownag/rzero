## Notes
- Analysis facts:
  - `tests/r0/` does not exist yet; creating `allowlist.txt` creates the directory. No `.R0` files exist, so the runner must pass on an empty corpus.
  - `tests/gnu_r.rs` has `CANON_R` (absolute path to `canon.R`), `canon_r0(&R0Val) -> String` (lines joined by `\n`, no trailing newline), `rscript_available()`, `TEMP_COUNTER`, and `canon_via_rscript(&str)`. `canon_via_rscript` takes an expression and is not reused; the runner builds a whole-file script.
  - `R0Vm::new(i64)` and `eval_script(&mut self, &str) -> Result<R0Val, String>` (`src/vm.rs` 58, 87). `tests/conformance.rs` uses `R0Vm::new(...).eval_script(src)` without `mut`, which works only on temporaries.
  - Rscript is `/usr/bin/Rscript` (R 4.6.2), present.
  - Trailing newline: R side `writeLines` adds one; trim trailing `\n` from stdout before comparing (as 6.1.1 does).
- Constraints honored: `Rscript` gets a file argument only; temp names unique via pid plus atomic counter; no `Cargo.toml` change; no `src/**`, `canon.R`, `Makefile`, `docs/**`, or `.R0` edits.
- Risks:
  - The runner body cannot be exercised end-to-end until 6.2.x adds a `.R0` file; the empty-corpus acceptance does not hit the mismatch or stale branches. Verification of those branches is deferred to 6.2.1 or 6.3.1 unless a temp-corpus self-test is approved.
  - Stdout from R may contain R warnings or messages on stderr only; stdout is used alone, so warnings do not corrupt the comparison.
  - `format!("{:?}")` of a path inside R `parse(file = ...)` is valid R for ASCII paths only; the repo path is ASCII.
