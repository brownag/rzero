## Notes
- Df/List `len()` is nrow of first column, so ncols = `cols.len()`.
- Existing `subset` rejects Df/List today with a TypeError; that arm becomes column selection (existing test, if any, asserting the error will be updated).
- Atomic-vector `Index1` behavior untouched (its OOB -> NA rule stays; the strict OOB error applies only to Df/List and Index2 per Decision Log).
- Rows on a zero-column Df: nrows = 0.
- Atomic target with `Index2` -> `TypeError` (spec item 4).
