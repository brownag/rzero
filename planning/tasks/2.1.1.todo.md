## Notes
- Fuel metering constraint: `self.consume_fuel(n)` must be called strictly before allocating output vectors in constructors.
- Shape intrinsics (`nrow`/`ncol`): return `R0Val::Int(vec![count])` for `R0Val::Df`, and `R0Val::Null` for atomic vectors/`Null`/other types.
- Prelude locking: `VM::is_intrinsic` check inside `Expr::Assign` prevents user functions from shadowing these intrinsics.
- Scope constraints: Only `src/vm.rs` is modified; `tests/conformance.rs` and `docs/LANGUAGE_SPEC.md` remain untouched until Wave 4.
