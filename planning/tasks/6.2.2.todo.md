## Notes
- Runner: `tests/gnu_r.rs` reads `tests/r0/*.R0` (extension `R0`), evaluates with `R0Vm::eval_script`, and with `Rscript` via `parse(file=)` in a fresh env. Last top-level expression is the result. `reject:` lines go to stdout.
- Parser: `Tok::Dollar` (`$`) exists at `src/parser.rs:104`; `while`, `break`, `next` are keywords (`src/lexer.rs:242-247`); `Expr::Break`/`Expr::Next` at `src/parser.rs:181-182`.
- `[[`: `index_scalar` (`src/vm.rs:818`) takes only a numeric 1-based scalar. `lst[["name"]]` is therefore omitted per spec item 2; not used in any file.
- `data.frame(...)`, `d[2, "c"]`, `d[, ]`, `d[-1, "a"]` covered by `conformance_g9_extract_index_kinds` (`tests/conformance.rs:1882`).
- Short row mask is rejected by R0 (`ErrDimensionMismatch`, conformance line ~1892). Every row mask in the corpus is full-length (3 rows) to avoid rejects.
- Assignment: `conformance_g9_assign_2d` (`tests/conformance.rs:1960`) covers `d[2, 1] <- 9`, `d[2:3, 1:2] <- 0` style, and `d[1, ] <- 0`.
- `bracket_assign_df_cells` (`src/vm.rs:5522`) confirms `d[1:2, 1:2] <- c(10,20)` recycles column-major. Scalar recycling is in the spec.
- `null_df_and_list_access` (`src/vm.rs:3834`) confirms `d$a`, `d[1L]` on a data frame.
- Loops: no loop is the final expression. Each program ends on a plain variable or indexing expression.
- Risks: (a) `d["b"]` string-index column selection may not be supported in R0 (the Rust test uses `d[1L]`, numeric). If R0 rejects it, the file is reworked with numeric `d[2]` and reported under Deviations. (b) `lst[c(1, 3)]` on a list might return a shape canon does not match; a mismatch STOPs per spec. (c) `while (TRUE)` depends on the parser accepting `TRUE` as a literal in a loop head.
- Canon: data frame and list results go through `tests/gnu_r/canon.R`, which I do not touch.
