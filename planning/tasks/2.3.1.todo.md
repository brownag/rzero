# 2.3.1 -- Sequence & repetition (`rep`, `rep_len`, `seq`)

## Goal
Implement `rep`, `rep_len`, and `seq` in `VM::call_intrinsic` with locked prelude registration, argument binding, deterministic pre-allocation fuel metering, and unit tests covering normal execution and edge cases.

## Notes
- `is_intrinsic` at `src/vm.rs:315` prevents shadowing via user function definition (`sum <- function(x) ...`); adding `rep`, `rep_len`, `seq` enforces locked prelude semantics.
- Pre-allocation fuel metering: `self.consume_fuel(out_len)` is invoked before any `Vec::with_capacity(out_len)` or `vec![]` is allocated.
- Cyclic repetition index `(i / each) % x.len()` elegantly supports `each`, scalar `times`, and `length.out` across atomic types without intermediate vector allocations.
- Empty vector with positive `length.out` errors as required by spec; `length.out = 0` returns empty vector of matching type (or `Null` if `x` is `Null`).
- `seq` supports lazy `Range` for integer-step sequences where appropriate, while charging fuel for range length up-front.
- Constraints honored: only `src/vm.rs` and `planning/tasks/2.3.1.todo.md` in scope. No changes to `tests/conformance.rs` or `docs/LANGUAGE_SPEC.md`.
