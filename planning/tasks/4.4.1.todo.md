- Conformance helper `assert_val` tests value equality via `format!("{:?}", ...)`, while `eval_err` tests error reporting. For tests differentiating `NA_real_` and `NaN` in double vectors, use pattern matching on `eval(...)` with `is_na_real` or `v.is_nan()`.
- G8 intrinsics to cover (10): `which.min`, `which.max`, `match`, `unique`, `duplicated`, `sort`, `order`, `rank`, `tabulate`, `findInterval`.

- All 10 G8 intrinsics must be verified against shadowing (`Cannot shadow built-in intrinsic`).
- All 10 G8 intrinsics must be verified for fuel exhaustion on large inputs (`1:2000000000` or `1:100000`).
