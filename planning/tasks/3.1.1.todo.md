## Notes
- `is_intrinsic` at `src/vm.rs:315` locks prelude intrinsics against user function shadowing.
- `is.finite` and `is.infinite` return element-wise logical vectors. In R, `NA` and `NaN` are neither finite nor infinite (`is.finite(NA)` is `FALSE`, `is.infinite(NA)` is `FALSE`, `is.infinite(Inf)` is `TRUE`, `is.infinite(-Inf)` is `TRUE`).
- `any` and `all` follow GNU R 3-valued Kleene logic:
  - `any`: `TRUE` if any element is `TRUE` (even with `NA`); `NA` if no `TRUE` and at least one `NA` (`na.rm = FALSE`); `FALSE` for empty (`logical(0)` / `NULL`) or all `FALSE`.
  - `all`: `FALSE` if any element is `FALSE` (even with `NA`); `NA` if no `FALSE` and at least one `NA` (`na.rm = FALSE`); `TRUE` for empty (`logical(0)` / `NULL`) or all `TRUE`.
  - Non-logical/numeric inputs (e.g. `character`, `list`, `data.frame`) error with `TypeError`.
- `anyNA` returns scalar `Logical` (`true` if any element is `NA` or `NaN`, `false` otherwise; `false` for empty).
- All 5 intrinsics charge fuel `self.consume_fuel(x.len())?;` before allocating or scanning.
- Scope constraint honored: only `src/vm.rs` was modified during execution.
