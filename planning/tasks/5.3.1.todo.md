## Notes
- No `cargo fmt`. Existing `subset_assign` rejects Df/List bases, so 1-index Df/List needs the new branch in the Assign arm.
- `subset_assign` extends on positive OOB; we pre-validate rows via `resolve_index` (errors on OOB) so no growth occurs.
- 2D on a `List` base: error (2D is Df only, matching `subset2`).
- Atomic `x[j] <- v` behavior untouched.
