## Notes
- Discovered in Analysis:
  - Total implemented intrinsics count rises from 39 to 60 (27 initial + 12 G6 + 21 G7), and capability entries from 41 to 62.
  - `any` and `all` enforce GNU R 3-valued Kleene logic with named `na.rm = FALSE` default; reject `Chr`, `Df`, `List` with `TypeError`.
  - `is.finite` and `is.infinite` return `Lgl` vector matching input length; `NA`/`NaN` are not finite; `is.infinite` only matches `Inf`/`-Inf`.
  - `anyNA` returns scalar `Lgl` (`TRUE` if any `NA_real_`, `NaN`, `NA_INT`, `LGL_NA`, or `NA_character_` present).
  - `round` takes scalar integer/numeric `digits` (default 0) and implements IEEE 754 round-to-even (`round_ties_even`).
  - `atan2` takes `(y, x)` positional arguments (R parameter order), strictly checks recycling multiple (`ErrDimensionMismatch`), and returns empty `Dbl` if either argument is empty.
  - `prod` returns `1.0` for empty/Null inputs; `var`/`sd` return `NA_real_` when $n < 2$; `median` sorts non-missing values and averages middle two for even length.
  - `cumprod`, `cummin`, `cummax` propagate `NA`/`NaN` payloads stickily to all subsequent positions.
  - §7.2 drops from 31 to 10 unimplemented intrinsics (only the 10 extrema, search, sorting & binning functions remain unimplemented).
