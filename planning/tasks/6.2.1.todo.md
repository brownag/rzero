## Notes
- Facts: runner (`tests/gnu_r.rs`, `r0_corpus_matches_gnu_r`) reads `tests/r0/*.R0` by uppercase extension, evaluates with `R0Vm::new(1_000_000).eval_script`, prints `reject: <stem>` on R0 error, fails on mismatch or stale allowlist. Allowlist currently has no entries (`tests/r0/allowlist.txt`).
- Source of valid programs: `tests/conformance.rs` `broadcast_scalar_vector` (`1 + c(10, 20)`), `broadcast_equal_length` (`c(1, 2) + c(3, 4)`), `index_positive` (`x <- c(10,20,30)`, `x[1]`), `index_oob_na_padding` (uses `99L`; spec asks for Dbl index, so I use `x[5]`), `index_negative_drop`. Intrinsic names confirmed in `docs/LANGUAGE_SPEC.md` §7.1 (`sum`, `mean`, `min`, `max`, `which`, `seq_along`, `pmin`, `pmax`, `round`, `atan2`).
- Constraints honored: `<-` only if assignment is used at all (item 10 uses it); no `fn`, `->`, type hints, loops, or integer overflow.
- Plan layout: 12 files; `round` and `atan2` are grouped into the last file (item 12) to stay within the 8-12 range. Items 8, 9 and 12 each combine several sub-checks in one `c(...)` result.
- Risks: (a) R0 may reject `na.rm` on `pmin`/`pmax`, or `NA` as a bare logical in arithmetic; a reject violates acceptance and triggers STOP. (b) `round` ties: GNU R uses IEC 60559 round-half-even (`round(0.5)` = 0, `round(2.5)` = 2); R0 may differ, which would be a src defect (STOP). (c) Int vs Dbl canonical form is handled by the runner's `canon`; mixed-type `c(...)` results coerce to Dbl in GNU R.
- Possible conflict: spec asks for 8-12 files and a long list of coverage. Grouping resolves this, and the 12-file cap stays.
