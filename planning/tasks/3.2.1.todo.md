## Notes
- `is_intrinsic` at `src/vm.rs:315` locks all 9 intrinsics against user function shadowing.
- Unary math (`sin`, `cos`, `tan`, `acos`, `asin`, `atan`, `trunc`) promotes `Dbl`, `Int`, `Range` via `promote_dbl`, returns `Dbl`, and maps `Null` to `numeric(0)`.
- When input elements are missing (`is_missing(v)`), the original `f64` value `v` is returned as-is to preserve distinction between `NA_real_` (1954 payload) and quiet `NaN`.
- `round(x, digits = 0)` implements IEEE-754 round-to-even (banker's rounding via Rust's `f64::round_ties_even`) with powers of 10 scaling for positive and negative digits.
- `atan2(y, x)` binds `y` and `x` positionally/by name, returns `numeric(0)` if either operand is empty, enforces that the longer length is an exact multiple of the shorter length, and recycles indices with `i % ny` and `i % nx`.
- Fuel is charged upfront based on vector lengths (`x.len()` for unary and `round`, `ny.max(nx)` for `atan2`).
- Constraints honored: only `src/vm.rs` will be modified during implementation; `tests/conformance.rs` and `docs/LANGUAGE_SPEC.md` remain untouched.
