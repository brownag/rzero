# 7.2.1 -- Non-scalar `na.rm` is an error

## Goal
Make `parse_na_rm` reject any logical `na.rm` whose length is not 1 with an `ErrInvalidCondition:` error, so `sum(c(1L, NA_integer_), na.rm = c(TRUE, FALSE))` and `pmin(1L, NA_integer_, na.rm = c(FALSE, TRUE))` fail as GNU R does, while length-1 `TRUE`/`FALSE`, `NA`, and non-logical behaviour stay unchanged.
