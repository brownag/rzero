All return `Result<R0Val, String>`. Call sites (lines 127, 179, 184, 188) match these signatures, so they stay unchanged.
  - The task spec says "three" subsetting stubs. There are four. All four are replaced here, and `call_intrinsic` stays.
  - `value.rs` gives `na_of_type_like(n)`, `len`, `materialize_int`, `promote_dbl`, `is_na_real`, `NA_INT`, `LGL_*`. `R0Val::Df`/`List` have `names`/`cols` fields. `Expr::Field` is at `ast.rs:30`. None of these need changes.

  - Prototype `subset_assign` (line 1947) also promotes everything to Dbl. It also silently skips out-of-range and NA indices. Replace with a type rule: keep target, promote Int->Dbl only (D3).
  - Prototype `IndexScalar` (line 1681) returns `ErrBoundsTrap:` and handles Range as Int. Reuse those semantics as written.
  - Prototype `Field` (line 1697) errors with `Unknown column '$name' in data.frame`. The spec text (1.5.2 bullet) is `Unknown column '$name'`. The spec text is used here.
  - The existing `stubs_report_not_implemented` test (line 463) asserts `ErrNotImplemented: subset`. That assertion becomes false by design, so it is removed in this task.
  - `1:3` works in 1.5.1 (`Colon` range), so Range-subset tests need no `c()`.
- **Constraints honored.** Only `src/vm.rs` is edited. `value.rs`, `ast.rs`, `parser.rs`, `lexer.rs` are untouched. `call_intrinsic` stays a stub. Test helper `same()` compares Debug forms, since `R0Val` has no PartialEq. No new dependencies.

## Questions
1. **NA in a logical mask on assignment.** The prototype skips NA positions. Proposed fix: skip them, so only TRUE positions are written. R errors on NA here. Approve skip, or make NA an error?
2. **`[` and `[[` on Df/List bases.** The spec does not say. Proposed fix: `x[i]` and `x[[i]]` on Df/List give `TypeError:`, and `$` is the only access path. Alternative: `x[[i]]` on a List returns the i-th column. Which?
3. **Out-of-range positive index on assignment** (`x[5L] <- 1` on length 3). The prototype ignores it. Proposed fix: ignore, to match the prototype. Alternative: extend with NA padding, as R does. Which?
4. **Error prefix for assignment length mismatch.** Mask length or RHS length does not match. Proposed fix: `ErrDimensionMismatch:` for both, to match the read path. Approve?
5. **Assignment into `Null` or `Df`/`List` targets.** The spec is silent. Proposed fix: `Null` target gives `TypeError:`, and `Df`/`List` targets give `TypeError:`. Approve?
