## Notes
- Only `src/vm.rs` is in scope. Do not touch `tests/conformance.rs` or `docs/LANGUAGE_SPEC.md`.
- `prod`, `var`, `sd`, `median` all produce `R0Val::Dbl` scalar values.
- `cumprod`, `cummin`, `cummax` produce `R0Val::Dbl` vectors.
- `prod(numeric(0))` evaluates to `1.0`.
- `var` and `sd` return `NA_real_` when $n < 2$ after NA handling.
- `median` returns `NA_real_` when empty or when NA is present with `na.rm = FALSE`.
- Cumulative intrinsics propagate missingness: once NA/NaN is seen, all subsequent elements are NA/NaN.
