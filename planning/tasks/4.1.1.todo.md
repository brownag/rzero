## Notes
- Only `src/vm.rs` is in scope. Do not touch `tests/conformance.rs` or `docs/LANGUAGE_SPEC.md`.
- Intrinsics are registered in `is_intrinsic(name: &str) -> bool` and their parameter signatures in `call_intrinsic`.
- `which.min` and `which.max` return 1-based scalar `Int` (`R0Val::Int(vec![idx])`) or `integer(0)` (`R0Val::Int(Vec::new())`) if empty or all NA/NaN; character inputs reject with TypeError.
- `match` takes `(x, table, nomatch = NA_integer_)`. Equality and missingness semantics match `%in%`: `NA` matches `NA`, `NaN` matches `NaN`, but `NA` and `NaN` do not match each other. Fuel charge is proportional to `x.len() * table.len()`.
- `unique` preserves first-occurrence order and returns same type as `x`; `duplicated` returns `R0Val::Lgl` (`LGL_FALSE` on first occurrence, `LGL_TRUE` on subsequent). Float deduplication treats `+0.0` and `-0.0` as identical, and distinguishes `NA_real_` from `NaN`.
- Shadowing protection via `is_intrinsic` prevents user functions from shadowing these 5 intrinsics.
