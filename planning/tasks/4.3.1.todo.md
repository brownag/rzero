## Notes
- `tabulate`: Ignores `<= 0` and `NA`s in `bin`. Supports `Int`, `Dbl` (truncated to integer), `Range`, `Null`. Default `nbins` is `max(1, bin)` ignoring `<= 0` and `NA`. If no positive values, `nbins = 1`. Returns `R0Val::Int` of length `nbins`. Charges fuel proportional to `bin.len() + nbins`.
- `findInterval`: Validates that `vec` is sorted non-decreasingly and contains no missing values (`NA_real_` or `NaN`), erroring with `'vec' must be sorted non-decreasingly and not contain NAs` if violated. Supports `Int`, `Dbl`, `Range`, `Lgl`. Missing values in `x` preserve `NA_INT`. Uses binary search (`partition_point`). Charges fuel proportional to `x.len() * vec.len()`.
- `approx`: `rule` parameter defaults to `1` (NA outside range). When `rule = 2`, boundary values clamp to `y[0]` (left) and `y.last()` (right). Supports vector `rule` of length 1 or 2 with values in `{1, 2}`.
- `diff`: `lag` parameter defaults to `1`. Must be a positive integer `>= 1`. When `x.len() <= lag`, returns empty `numeric(0)` (`R0Val::Dbl(Vec::new())`). Missing values propagate according to IEEE-754 / R rules.
- Prelude locking: shadowing `tabulate` or `findInterval` with a user function triggers `Compile/Scope Error: Cannot shadow built-in intrinsic '<name>'`.
- Strict scope: only modify `src/vm.rs`. `tests/conformance.rs` and `docs/LANGUAGE_SPEC.md` are not touched.
