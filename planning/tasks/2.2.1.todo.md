## Notes
- Fuel metering constraint: `self.consume_fuel(x.len())` must be called strictly before allocating output vectors.
- Float parsing for `as.numeric(Chr)`: trims whitespace, parses float with `parse::<f64>()`, yielding `na_real()` on parse failure or `None` (`NA_character_`). Preserves distinct `NaN` vs `NA_real_`.
- Integer truncation for `as.integer(Dbl)`: finite floats truncate toward zero (`d.trunc()`), mapping `NaN`, `NA_real_`, `Inf`, and out-of-range values (< i32::MIN + 1 or > i32::MAX) to `NA_INT`.
- String parsing for `as.integer(Chr)`: parses integer directly or truncates parsed float toward zero; invalid strings, `None`, and out-of-range values become `NA_INT`.
- Logical parsing for `as.logical(Chr)`: recognizes `"TRUE"`, `"T"`, `"true"`, `"True"` as `LGL_TRUE`, `"FALSE"`, `"F"`, `"false"`, `"False"` as `LGL_FALSE`, and any other string or `None` as `LGL_NA`.
- `Null` handling: `as.numeric(NULL)` -> `Dbl(vec![])`, `as.integer(NULL)` -> `Int(vec![])`, `as.logical(NULL)` -> `Lgl(vec![])`.
- Non-atomic types (`Df`, `List`): rejected with `TypeError` / unsupported type error.
- Range support: `R0Val::Range` represents an atomic integer vector and coerces directly to double (`promote_dbl`), integer (`materialize_int`), or logical (`!= 0`).
- Scope constraints: only `src/vm.rs` and `planning/tasks/2.2.1.todo.md` are touched; no edits to `tests/conformance.rs` or `docs/LANGUAGE_SPEC.md` during Wave 2.
