## Notes
- `r0_transpiled_matches_gnu_r` already fails an R0 error (`R0 rejected`) and transpile/Rscript errors as failures. No skip path, so no change needed there.
- `r0_corpus_matches_gnu_r` filters via `is_r0_only`, which currently matches only `g12_`; the one-function change covers both tests.
- Format: plain `.R0` script, last expression is compared via `canon` against transpiled R run under `Rscript --vanilla`. Existing example: `tests/r0/g12_transpile.R0`.
- Syntax per conformance tests: `fn(x) ...`, `function(x) ...`, `\(x) ...` (to confirm that the lexer accepts `\(`; from 12.1.2), `l$f(1)`, `(fn(x) x)(2)`.
- Risk: the `\` form is lexed in 12.1.2; the test run verifies it. Risk: late reassignment relies on 12.4.1 (`x <- 1; f <- fn() x; x <- 2; f()` gives 2).
- Planned files in tests/r0/:
  - g_anon_fn.R0 (`(fn(x) x + 1)(2)`)
  - g_anon_function.R0 (`(function(x) x * 2)(4)`)
  - g_anon_backslash.R0 (`(\(x) x - 1)(5)`)
  - g_anon_factory.R0 (`make <- fn(k) fn(x) x + k; add2 <- make(2); add2(3)`)
  - g_anon_list_fn.R0 (`l <- list(f = fn(x) x + 1); l$f(1)`)
  - g_anon_arg.R0 (`apply_twice <- fn(h, v) h(h(v)); apply_twice(fn(x) x * 3, 2)`)
  - g_anon_default.R0 (`(fn(x, y = 10) x + y)(1)`)
  - g_anon_late_reassign.R0 (`x <- 1; f <- fn() x; x <- 2; f()`)
- No `src/`, `docs/`, or `tests/conformance.rs` changes.
