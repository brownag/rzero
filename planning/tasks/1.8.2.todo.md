## Notes
- Only file in scope: `tests/conformance.rs`. No `src/` edits. If a test fails because of a `src/` bug, STOP and report (do not fix).
- Evaluator facts (from `src/vm.rs` and `src/value.rs`):
  - `&`/`|` use `KLEENE_AND_LUT` / `KLEENE_OR_LUT` (value.rs:25); unit test `kleene_and_and_short_circuit` already pins `FALSE & NA`=FALSE, `TRUE & NA`=NA.
  - `!` is `UnaryOp::Not` over `Lgl` via `KLEENE_NOT_LUT`.
  - `broadcast_len` (vm.rs:280) allows equal length or length-1 only; otherwise `ErrDimensionMismatch:` (unit test `broadcast_scalar_and_dimension_mismatch` covers same shapes).
  - `extract_scalar_cond` (vm.rs:264) returns `ErrInvalidCondition:` for NA and for length != 1 (unit test `invalid_conditions_trap` covers `if (NA)` and a length-2 variable; the new test uses `c(TRUE, FALSE)` literal form).
  - `c(TRUE, FALSE)` with only logicals returns `Lgl` (common_concat, vm.rs:616), so the literal form in the spec works.
  - Lexer: `TRUE`/`FALSE`/`NA` become `LglLit` (lexer.rs:231-233); `1` is a `Dbl`, so `1 + c(10, 20)` yields `Dbl`.
- Expected 9-pair table (standard Kleene, spec anchors marked *):
  - `&`: FALSE&FALSE=F, FALSE&TRUE=F*, FALSE&NA=F*, TRUE&FALSE=F, TRUE&TRUE=T, TRUE&NA=NA*, NA&FALSE=F, NA&TRUE=NA, NA&NA=NA*.
  - `|`: FALSE|FALSE=F, FALSE|TRUE=T, FALSE|NA=NA*, TRUE|FALSE=T, TRUE|TRUE=T, TRUE|NA=T*, NA|FALSE=NA, NA|TRUE=T, NA|NA=NA.
- Comparison: `R0Val` has no PartialEq; compare `format!("{:?}")` via the existing `assert_val` helper.
- Test names must start with `kleene_` or `broadcast_`. Existing helpers `eval`, `eval_err`, `assert_val` are reused.
- Dependency 1.8.1 (same file) is already committed (`bc04e8a`, `975d6ef` E14 fix). `c()` numeric path is only used with Dbl operands here, so E14 does not affect these tests.
- Risk: the 9-pair table is a loop; a failing pair should report its source string (use the `src` in the assert message) so the failure is diagnosable.
