## Notes
- Only `src/vm.rs` is in scope. Do not touch `tests/conformance.rs` or `docs/LANGUAGE_SPEC.md`.
- Intrinsics are registered in `is_intrinsic(name: &str) -> bool` and their parameter signatures in `call_intrinsic`.
- Fuel consumption is charged as `if n <= 1 { n } else { n.saturating_mul((n as f64).log2().ceil() as usize).max(n) }`, preventing memory exhaustion on huge lazy ranges (`1:2000000000`).
- `sort(x, decreasing = FALSE)` drops `NA`s/`NaN`s by default (`na.last = NA`), returns vector of same type as non-NA elements (or `Range` for ranges, `Null` for null).
- `order(x, decreasing = FALSE)` returns 1-based `Int` permutation indices (`R0Val::Int`), stable tie-breaking on ties, with all `NA`s and `NaN`s placed last at the end in their original relative order even when `decreasing = TRUE`.
- `rank(x)` returns `Dbl` vector of 1-based sample ranks (`R0Val::Dbl`). Equal non-missing values receive their average rank; `NA` and `NaN` values are never considered equal to each other or non-NAs and receive distinct consecutive ranks at the end in order of occurrence.
- Shadowing protection via `is_intrinsic` prevents user functions from shadowing `order`, `sort`, and `rank`.
