## Notes
- `R0Val::Fn(UserFnValue)` where `UserFnValue = Box<vm::UserFn>` (value.rs:91,117); UserFn fields are pub(crate), so constructible in vm.rs.
- List is `R0Val::List { names, cols }`; `list(...)` intrinsic (vm.rs ~2309) just pushes evaluated args, so Fn values need no intrinsic change. Names are required.
- Args are evaluated by `Expr::Call` via `self.eval`, so a Fn value passes as an ordinary arg and is bound into `local_env` by `call_user` (clones `captured_env`, inserts params); no change needed.
- Value-position Fn is NOT callable yet (calls dispatch by name via `self.functions`; 12.3.1/12.3.2). Tests must not call it.
- Capture: `env.clone()` snapshot, same as named functions.
- Risk: `R0Val::Fn` in `length`/printing already handled by 12.1.1 (length 1, Display placeholder). `eval_script` returning a Fn result is fine at the Rust level.
- Risk: conformance helper `assert_val` compares Debug output; I use `matches!`/`length` instead.
